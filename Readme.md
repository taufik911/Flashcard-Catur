Deskripsi Projek

Projek ini adalah sebuah aplikasi web 1 halaman (Aplikasi Flashcard Pembukaan Catur) yang berfungsi untuk melatih hafalan nama-nama pembukaan dalam permainan catur.

Pemenuhan Syarat Tugas:

✅ Tampilan (HTML + CSS)

Memiliki judul halaman (Nama Mahasiswa di tag <title> atau <header>).

Memiliki minimal 4 teks (terdapat Heading untuk judul, dan beberapa paragraf/teks untuk instruksi serta isi kartu).

Memiliki elemen desain (Menggunakan framework Bootstrap dan CSS kustom untuk warna background kartu dan efek transisi).

✅ Interaksi (JavaScript)

Memiliki tombol interaktif:

Saat kartu diklik, JavaScript akan memanipulasi DOM untuk mengubah teks pertanyaan menjadi teks jawaban dan mengubah warna kartu.

Saat tombol "Kartu Selanjutnya" diklik, JavaScript akan memuat data array berikutnya secara dinamis.
