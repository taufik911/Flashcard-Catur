# Flashcard Pembukaan Catur - Tugas Pemrograman Web 1

Repositori ini dibuat untuk memenuhi penugasan praktikum mata kuliah Pemrograman Web 1 (Pertemuan 5) di Universitas Teknologi Bandung. Proyek ini mengimplementasikan sebuah aplikasi web satu halaman (*single-page application*) interaktif yang dibangun menggunakan kombinasi HTML, CSS, JavaScript, dan framework Bootstrap 5[cite: 1].

Aplikasi web Flashcard Pembukaan Catur ini dikembangkan sebagai bentuk implementasi praktis dari materi perkuliahan Pemrograman Web 1[cite: 1]. Menggunakan pendekatan *single-page application* yang efisien, proyek ini memadukan struktur HTML modern, gaya tata letak dari Bootstrap 5, serta skrip JavaScript interaktif dalam satu file tunggal yang ringan dan mudah diakses[cite: 1].

Dari sisi fungsionalitas dan antarmuka, aplikasi ini dirancang secara intuitif untuk membantu pengguna menghafal berbagai variasi langkah dan nama pembukaan catur secara mandiri. Pengguna dapat mengeklik kartu interaktif untuk melihat jawaban atau nama pembukaan secara langsung, serta memanfaatkan tombol navigasi untuk beralih ke soal latihan berikutnya secara dinamis.

Proyek ini tidak hanya memenuhi standar penugasan akademik yang interaktif dan responsif[cite: 1], tetapi juga mencerminkan hobi serta minat pribadi dalam dunia catur. Dengan menggabungkan hobi strategis tersebut ke dalam pengembangan perangkat lunak, aplikasi ini menjadi sarana belajar yang fungsional sekaligus portofolio awal yang menarik.

## 📋 Pemenuhan Syarat Tugas
* **Tampilan (HTML + CSS):** Memiliki judul halaman, minimal 4 elemen teks (Heading dan beberapa paragraf), serta elemen desain warna latar dan kartu menggunakan Bootstrap
* **Interaksi (JavaScript):** Memiliki tombol interaktif dan fungsi manipulasi DOM untuk mengubah teks serta memuat data array secara dinamis saat kartu atau tombol diklik
