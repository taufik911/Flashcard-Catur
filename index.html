TAUFIK HIDAYAT

Aplikasi web Flashcard Pembukaan Catur ini dikembangkan sebagai bentuk implementasi praktis dari materi perkuliahan Pemrograman Web 1. Menggunakan pendekatan single-page application yang efisien, proyek ini memadukan struktur HTML modern, gaya tata letak dari Bootstrap 5, serta skrip JavaScript interaktif dalam satu file tunggal yang ringan dan mudah diakses.

Dari sisi fungsionalitas dan antarmuka, aplikasi ini dirancang secara intuitif untuk membantu pengguna menghafal berbagai variasi langkah dan nama pembukaan catur secara mandiri. Pengguna dapat mengeklik kartu interaktif untuk melihat jawaban atau nama pembukaan secara langsung, serta memanfaatkan tombol navigasi untuk beralih ke soal latihan berikutnya secara dinamis.

Proyek ini tidak hanya memenuhi standar penugasan akademik yang interaktif dan responsif, tetapi juga mencerminkan hobi serta minat pribadi dalam dunia catur. Dengan menggabungkan hobi strategis tersebut ke dalam pengembangan perangkat lunak, aplikasi ini menjadi sarana belajar yang fungsional sekaligus portofolio awal yang menarik.
